# غَرْس — تطبيق صقل الشخصية (نسخة PWA مستقلة)

تطبيق ويب مستقل تماماً، لا يحتاج Claude ولا إنترنت بعد أول فتحة. البيانات تُحفظ داخل متصفح هاتفك فقط (بلا تسجيل دخول، وبلا خادم).

## الملفات
- `index.html` — الصفحة الرئيسية
- `app.js` — كل منطق التطبيق
- `manifest.json` — بيانات التثبيت كتطبيق
- `service-worker.js` — يفعّل العمل بدون إنترنت
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — أيقونات التطبيق

## طريقة الاستضافة (اختر واحدة، مجانية بالكامل)

### الخيار الأول: Netlify Drop (الأسهل، دقيقتان)
1. افتح **app.netlify.com/drop** من حاسوبك.
2. اسحب مجلد `ghars-pwa` بالكامل وأفلته في الصفحة.
3. سيعطيك رابطاً مباشراً (مثل `random-name.netlify.app`).
4. افتح هذا الرابط من متصفح هاتفك (Safari لآيفون، Chrome لأندرويد).
5. من قائمة المتصفح اختر **"Add to Home Screen" / "إضافة إلى الشاشة الرئيسية"**.

### الخيار الثاني: GitHub Pages
1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع كل ملفات مجلد `ghars-pwa` إليه.
3. من إعدادات المستودع (Settings → Pages) فعّل النشر من الفرع الرئيسي (main).
4. بعد دقيقة سيصبح متاحاً على رابط بصيغة `username.github.io/repo-name`.
5. افتحه من هاتفك وأضِفه للشاشة الرئيسية كما في الخطوة أعلاه.

## بعد التثبيت
- ستظهر أيقونة "غَرْس" على شاشتك الرئيسية، وتفتح بملء الشاشة كتطبيق حقيقي.
- يعمل بدون إنترنت بعد أول فتحة (الصفحة والأيقونات محفوظة تلقائياً).
- البيانات محفوظة في هذا المتصفح تحديداً على هذا الجهاز؛ لا تُشارك مع أي جهاز آخر ولا مع Claude.
- إن مسحت بيانات المتصفح (Clear browsing data) لهذا الموقع تحديداً، ستُفقد بياناتك — تجنّب ذلك.

## تعديلات لاحقة
